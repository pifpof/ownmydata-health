# Code of Conduct

Own My Data.Health adopts the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/) as its code of conduct. Everyone taking part in the project's spaces (issues, pull requests, discussions, and any events or channels run for the project) is expected to follow it.

In short: be respectful and welcoming, assume good intent, accept that people disagree, and focus on what is best for the people this project serves. Harassment, personal attacks and discriminatory language are not acceptable.

## Health information is personal

This project is about health data, so one more expectation applies here. Never ask anyone about their health, never share someone else's health information, and never post your own real records in a project space. If someone mentions their own health while explaining why they care, treat it with respect and don't pursue it.

## Reporting

Report anything that breaks this code to **hello@parallel79.com**. Reports are handled privately. The maintainers will review each report and take the action they judge appropriate, following the Contributor Covenant's enforcement guidelines.
