# Sample vault (fictional)

`sample-vault/` is a complete health vault produced by running the v0.1.0 skills on the fictional documents in `../fixtures/`, in the order of the acceptance tests (setup as "Pat Sample", the ENT consult, the October lab report, a hearing-test sentence, the smudged lab photo, a correction, a confirmation, then "the ear thing is sorted" and `/ownmydata:save`, then `/ownmydata:health-check`).

Everything in it is fictional: Pat Sample, Example ENT Clinic, Example Medical Laboratory, Dr. A. Example and Dr. B. Familydoc do not exist.

The vault's own `.gitignore` is stored here as `_gitignore`, because a real `.gitignore` would hide the example's `memory/` and `data/` folders from this repository. In a real vault, setup installs it as `.gitignore`.
